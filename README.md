# BAtruOS

**Diagnose und Retrofit für ältere Heizungssteuerungen. Ein Anwendungsprojekt von [BAxxxOS](https://github.com/bastelalex/BAxxxOS).**

Wenn eine ältere Heizung ausfällt, kann die Fehlersuche an der Steuerung viel Zeit kosten. BAtruOS entwickelt dafür einen Werkstattablauf, der Zustände und Messverläufe sichtbar macht. Eine Werkstatt soll typische Fehler eingrenzen und ihre Ergebnisse so festhalten können, dass eine zweite Werkstatt sie nachvollziehen kann.

## RetroControl

Der erste Anwendungsfall ist die **Trumatic E1800**. **RetroControl H1** konzentriert sich auf die Diagnose am Prüfstand. Die Originalsteuerung behält ihre Sicherheitsfunktionen. Der erste Softwareprototyp arbeitet mit simulierten Messdaten. Als nächstes soll ein gasfreier Prüfstand zeigen, ob sich bekannte Fehler an Originalhardware wiederholbar eingrenzen lassen.

Langfristig soll der Diagnoseansatz auf weitere ältere Steuerungen übertragbar werden. Dafür sind **FixKit** mit geprüften Spenderbauteilen und **Ready2Löt** mit Neuteilen als zwei mögliche Kit-Varianten vorgesehen.

## English summary

BAtruOS is a BAxxxOS application for diagnosing and retrofitting legacy heater electronics. RetroControl starts with the Trumatic E1800 and aims to make fault finding repeatable for repair shops. The current software prototype uses simulated data, with bench validation on original hardware planned next.
