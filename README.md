# BAtruOS

Offene, herstellerübergreifende Plattform für Diagnose, Dokumentation und perspektivische Integration von Gas- und Dieselstandheizungen, Boilern und Elektroheizungen einschließlich Kombigeräten.

Ziel ist eine erweiterbare Unterstützung aller dieser Geräteklassen. Kompatibilität wird für jedes Modell und jede Hardware-/Firmware-Revision einzeln nachgewiesen; derzeit ist kein reales Gerät als unterstützt freigegeben.

[RetroControl](retrocontrol/README.md) beginnt mit der beobachtenden E1800-H1-Diagnose als Referenz. Gemeinsamer Kern, Geräteprofile und Adapter ermöglichen später weitere Hersteller, Energieträger und Schnittstellen. Siehe [Plattformumfang](retrocontrol/docs/platform-scope.md) und [Mitwirken](CONTRIBUTING.md).
